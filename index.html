📘 How teachers publish

  1. Open the repository on GitHub → notes folder.
  2. Add file → Upload files → drop your PDFs → commit.
  3. Each folder = one subject, e.g. notes/Physics/
  4. English + Hindi pair: Unit-1.pdf + Unit-1.hi.pdf
  5. Done — the blog updates itself in about a minute. New uploads appear as stories for 24 hours!

💡 Tips for students

  1. Tap a story circle on top for the freshest uploads.
  2. Tap 🔖 on any note to save it — find saved notes in the chip row.
  3. Use Files tab to browse every file with sizes & downloads.
  4. Reading offline? ⬇ download once — cached PDFs open without internet.

⚙️ About this app

Notes Sathi is the notes app of Satpuda College of Engineering and Polytechnic 🎓 — notes are published by Contributed Teachers and stay free for every student. No accounts, no tracking, no fees. Made with ❤️ by Vinay Soni. Installable as an app (Add to Home Screen) for offline reading.
