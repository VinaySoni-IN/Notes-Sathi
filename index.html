📘 How teachers publish

  1. Open the Upload tab in the app and sign in once with your GitHub token — a step-by-step guide is included there.
  2. Pick your Program, Branch, Semester and Subject — all required, so every note lands in the right folder automatically.
  3. Drag & drop your PDFs — 📘 English and 📕 हिंदी versions are detected automatically; tap to switch if needed.
  4. Tap Upload all → students see the notes within ~1 minute, with stories and a NEW badge for 24 hours.

Prefer GitHub directly? Upload into notes/Polytechnic/Civil Engineering/Sem 3/Building Construction/ (English + Hindi pair: Unit-1.pdf + Unit-1.hi.pdf). Student-submitted note? End the file name with the student's name — Unit-1.Priya Sharma.pdf — and the post gets a golden ✍️ By Priya Sharma badge. PYQ papers go in notes/Polytechnic/Civil Engineering/Sem 3/PYQ/ — they show up in the 📝 PYQ's sheet, not the feed.

💡 Tips for students

  1. Tap a story circle on top for the freshest uploads.
  2. Tap 🔖 on any note to save it — find saved notes in the chip row.
  3. Use Files tab to browse every file with sizes & downloads.
  4. Reading offline? ⬇ download once — cached PDFs open without internet.

Teacher sign-in

Sign in once with a GitHub fine-grained personal access token (only this repository, Contents: Read & write) and upload notes from here — no GitHub knowledge needed afterwards.

How do I create a token? (one-time, ≈2 minutes)
  1. Open github.com → Settings → Developer settings → Fine-grained tokens → Generate new token
  2. Name it Notes Upload, set a short expiry (30–90 days)
  3. Repository access → Only select repositories → Notes-Sathi
  4. Permissions → Contents: Read and write (nothing else needed)
  5. Generate, copy the token, and paste it above

🔒 The token is stored only in your browser and sent only to GitHub. Sign out on shared computers.
